# أصول | Osool — منصة الثروة والأصول الحقيقية الموثقة

منظومة متكاملة 360° لإدارة الذهب والأصول التشغيلية الموثقة، مع تجربة مستخدم جاهزة للتشغيل على GitHub Pages وتدفقات شحن/سحب المحفظة مع مراجعة إدارية.

## مميزات المنصة
1. **تطبيق المستثمر**: متابعة صافي الثروة، تداول الذهب المباشر، إدارة المحفظة، وأصول التشغيل المستثمرة.
2. **بوابة التجار (B2B)**: تمويل المعدات والطلبات التشغيلية مع العائد المتوقع.
3. **الرقابة الشرعية**: حوكمة AAOIFI، حاسبة الزكاة، ومؤشرات الشفافية.
4. **لوحة مدير المنصة**: مراجعة طلبات الشحن والسحب، وتحديث الرصيد بعد التأكيد اليدوي.
5. **نظام محفظة موثق**: شحن رصيد عبر تحويلات خارجية مع إرسال إثبات التحويل، وسحب عبر طلب مراجعة إداري.

## التشغيل المحلي
```bash
cd osool-platform
python3 -m http.server 8000
```
ثم افتح الرابط:
http://localhost:8000

## النشر على GitHub Pages
يتم نشر المشروع مباشرة من فرع `main` عبر GitHub Pages، بشرط أن يكون ملف `index.html` موجوداً في الجذر.
