# أصول | Osool — منصة الثروة والأصول الحقيقية الموثقة

منظومة متكاملة 360° لإدارة الذهب والأصول التشغيلية الموثقة (إجارة معدات، مرابحة طلبيات سريعة الدوران، وخزينة سبائك الذهب عيار 24).

## مميزات المنصة
1. **تطبيق المستثمر**: لوحة متابعة صافي الثروة، تداول الذهب الفوري بالخزينة، واستثمار تشاركي في المعدات الحقيقية.
2. **بوابة التجار (B2B)**: تمويل المعدات بنظام الاستقطاع التلقائي من نقاط البيع (POS Auto-Split).
3. **الرقابة الشرعية**: حوكمة وفق معايير AAOIFI وحاسبة زكاة تلقائية.
4. **غرفة عمليات المؤسس**: إدارة التسعير والعمولات وتقارير الشفافية للمستثمرين.
